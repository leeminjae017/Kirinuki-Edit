# 대시보드 가이드

화면에서 뺀 설명은 여기에 모았습니다. 대시보드는 `python dashboard/server.py --port 8899 --open` 으로 켭니다 ([README](../README.md)).

탭은 둘입니다:
- **AI 편집**: 지시하는 곳
- **사용자 편집**: 직접 고치고 굽는 곳

오른쪽 위 메뉴에서 프로젝트를 만들고 엽니다. 저장은 저절로 되고, `Ctrl+S` 로도 할 수 있습니다.

---

## 1. AI 편집 탭

| 칸 | 내용 |
|---|---|
| 왼쪽 | 스타일 적용 / 스타일 분석 |
| 가운데 | 지시 · 메모 (세로 영상일 때. 가로 영상이면 영상 아래) |
| 오른쪽 | 영상 |

### 스타일 적용 (1차 편집)

1. **편집 대상**에 원본 영상 (또는 폴더) 을 놓습니다.
2. **소스 파일**에는 넣을 그림 · 사진 · 효과음 · 예시 캡처를 놓습니다 (선택).
3. **스타일**과 **화면 비율**을 고릅니다.
   - 기본: 스타일 (프리셋) 에 적힌 비율 그대로
   - 9:16: 세로 (쇼츠 · 릴스 · 틱톡)
   - 16:9: 가로 (유튜브 본편)
   - 1:1: 정사각형
   - 4:5: 조금 세로 (인스타 피드)
4. 대상 영상이 둘 이상이면 **따로** (영상마다 한 편) / **하나로** (차례대로 이어 한 편) 를 고릅니다.
5. **스타일 적용** 단추를 누르면 작업 글이 Claude Code 로 넘어갑니다.

### 영상 위 지시 (쪽지)

1차 편집 전에는 편집 대상의 첫 영상이 영상 칸에서 틀어집니다. 그 위에 바로 지시를 그릴 수 있습니다.
- 브라우저에 놓은 파일이라 페이지를 새로 고치면 다시 놓아야 합니다. 쪽지는 남습니다.
- 쪽지 시각은 원본 시각으로, 자리는 화면 비율 (0–1) 로 작업 글에 실립니다.

| 도구 | 쓰는 법 |
|---|---|
| 메모 | 누른 자리에 번호 쪽지 |
| 영역 메모 | 끌어서 네모를 잡고 쪽지를 붙임 |
| 선 · 화살표 | 끌어서 긋기 |
| 곡선 화살표 | 끈 자취를 따라감 |
| 모두 지우기 | 이 영상의 쪽지 전부 |

쪽지 글은 메모 목록에서 두 번 눌러 적습니다.

### 지시 · 재편집

- **지시** 칸은 영상 전체에 대한 글입니다 (예: 컷 간격을 촘촘하게, 말소리가 잘린다, 여백이 길다).
- 1차 편집 때는 스타일 적용이, 그 뒤에는 **재편집** 단추가 지시와 쪽지를 같이 넘깁니다.
  재편집은 1차 편집이 끝나 장면이 생긴 뒤에만 됩니다.
- **자막 언어**는 쉼표로 구분합니다 (`ko, en, ja`). 영상 · 소리는 같고 자막만 언어 수만큼 만듭니다.
- **AI 호출**: 대시보드는 API 를 부르지 않습니다. 작업 글만 만들고 실행은 Claude Code 가 합니다.

### AI 가 지키는 것

- 1차 편집도 **굽지 않습니다.** 미리보기만 만듭니다 (`tools/preview_update.py`). 완성본은 사용자 편집 > 렌더에서 마지막에 한 번 굽습니다.
- 화면 잡기 · 확대 · 위치는 원본을 건드리지 않는 값 (크롭 · 카메라 · 화면 효과) 으로만 둡니다.
  그래서 1.6배로 잡혔어도 사용자 편집 탭에서 원본 클립 **변형**으로 1.5배로 되돌릴 수 있습니다 (원본에서 다시 잘라 화질 그대로).

## 2. 사용자 편집 탭

| 칸 | 위치 |
|---|---|
| 소스 / 이펙트 | 왼쪽 |
| 뷰어 | 가운데 |
| 인스펙터 / 전사 자막 / 렌더 | 오른쪽 |
| 타임라인 | 아래 |

칸 사이 손잡이로 크기를 바꾸고, 두 번 누르면 기본 크기로 돌아갑니다.

뷰어 위 **렌더 전** 표는 고친 것이 아직 안 구워졌다는 뜻입니다. 이때 미리보기는 원본 사본에서 지금 컷대로 이어 틉니다.

### 트랙

| 트랙 | 위치 | 내용 |
|---|---|---|
| V1 · A1 | 가운데 선 바로 위 · 아래 | 이 편 원본 |
| V2.. | V1 위로 | 덧 영상 · 그림 · **자막** |
| A2.. | A1 아래로 | 덧 소리 |

- 쓰는 트랙까지만 보입니다. 원본만 있으면 V1 · A1 만 보입니다.
- 클립을 끄는 동안에는 위 (오디오는 아래) 에 빈 트랙이 하나 더 생깁니다. 거기 놓으면 트랙이 늘어납니다.
- 끌다가 칸 끝에 닿으면 저절로 넘어갑니다.
- 놓을 자리는 주황 점선으로 보입니다 (올릴 때도 내릴 때도).
- 자막도 비디오 트랙에 놓입니다. 정하지 않은 자막은 V2 부터 비어 있는 트랙에 들어가고, 겹치면 한 칸 위로 갑니다.

### 클립 트랙 옮기기

- **원본 클립을 V2.. 로 끌기** (또는 우클릭 → 위 트랙으로):
  같은 원본 구간 · 같은 화면 (AI 크롭 · 변형 · 색 · 그룹) 의 덧 영상이 됩니다.
- **A1 소리를 A2.. 로 끌기**: 소리만 아래 트랙으로 갑니다. A1 자리는 빗금으로 표시되고, 그 구간 원본 소리는 0 이 됩니다.
- **연결 (고리) 아이콘**에 따라 달라집니다.
  - 켬: 영상과 소리가 같이 움직입니다. V1 · A1 에는 빈 틈이 남습니다.
  - 끔: 끈 쪽만 움직입니다. 남은 쪽은 빗금으로 표시됩니다.
- **원본에서 온 덧 영상 · 소리를 V1 · A1 에 끌어 놓으면** 원본 클립으로 돌아갑니다.
  - 빗금 자리가 있으면 그것을 되살립니다.
  - 두 프레임 안쪽으로 겹치면 옆 클립에 붙입니다.

### 그룹

1. 여러 클립을 고르고 우클릭 → **그룹 만들기** 를 눌러 이름을 붙입니다.
2. 그룹에 든 클립은 인스펙터에서 바꾼 값이 같은 갈래 (원본 / 그림 / 소리) 클립에 같이 들어갑니다.
3. 인스펙터 머리에 `그룹 이름 · N개` 가 보입니다.

### 인스펙터

비디오 / 오디오 탭으로 나뉩니다. 슬라이더를 두 번 누르면 기본값이 됩니다.

**변형 (이동 · 확대 · 회전)**
- 원본 클립에 걸면 AI 가 잡은 화면 위에 얹힙니다. 원본에서 다시 잘라 화질은 그대로이고, 원본 밖은 검게 나옵니다.
- X · Y 숫자는 보기만 합니다. 슬라이더나 뷰어 상자로 바꿉니다.
- **뷰어 상자**:
  - 가운데 끌기: 옮기기
  - 모서리 끌기: 비율 그대로 크기 (맞은편 고정, Alt = 가운데 고정)
  - 붙기 (N) 가 켜졌으면 화면 · 창 가장자리 · 가운데에 붙습니다.

**색**: 탭이 셋입니다.

| 탭 | 내용 |
|---|---|
| 밝기 · 대비 · 채도 | |
| RGBW | 리프트 (어두운 곳) · 감마 (중간) · 게인 (밝은 곳) 마다 R · G · B · W |
| 커브 | 전체 · R · G · B |

- 커브: 누르면 점이 생기고, 끌어 옮기며, 점을 두 번 누르면 뺍니다.
- **초기화**는 그 탭 (또는 그 커브) 만 처음대로 되돌립니다.
- 미리보기와 렌더는 같은 계산을 씁니다 (`shortsmith/lib/color.mjs`).

**키프레임 (덧 영상 · 그림)**
1. **키 추가**를 누르면 지금 재생 위치의 위치 · 크기가 키가 됩니다.
2. 그 뒤로는 위치 · 크기를 바꿀 때마다 (뷰어에서 끌어도) 그 시점에 키가 생깁니다.

나머지 단추:
- **◀ ▶**: 앞 · 뒤 키
- **부드럽게**: 키 사이를 천천히 출발해 천천히 멈춤 (끄면 곧게)
- **움직임 지우기**: 키를 다 지우고 지금 자리에 고정

**전환 (앞 클립에서)**
- 원본 클립: 바로 앞 클립에서 넘어오는 전환입니다.
- 덧 클립: 같은 트랙에서 끝이 이 클립 시작에 맞닿은 클립이 있어야 걸립니다.
- 디졸브 · 닦기 · 밀기 · 원형은 컷 가운데에 걸리고 두 파일의 클립 밖 부분을 씁니다.
  파일이 모자라면 짧아지고, 인스펙터에 실제 길이가 나옵니다.
- 검은 · 흰 화면은 컷 너머를 쓰지 않습니다.

**페이드 · 소리**
- 덧 클립 페이드는 화면 / 소리를 따로 둡니다.
- 소리는 dB 입니다. 브라우저는 1 배 넘게 키우지 못해, + dB 는 미리보기에서 1 배로 들립니다.

**자막**
- 글 · 화자 · 디자인 · 시작 · 끝 · 변형을 고칩니다.
- **원본 시작 · 끝**을 고치면 컷도 바뀝니다 (앞당기면 되살림, 늦추면 뺌).
- **컷에서 빼기** (Delete): 그 줄의 원본 구간을 컷에서 뺍니다.
- **자막** 단추로 새로 넣은 자막은 출력 시각에 섭니다. 끌어서 옮기고 Delete 로 지웁니다.

### 소스 / 이펙트 (왼쪽 칸)

**소스**
- 이 편 원본, **가져온 파일**, 추가한 폴더를 보여 줍니다. 파일을 타임라인으로 끌어 놓으면 클립이 됩니다.
- **바깥 파일 (탐색기에서 끌어 온 것)**:
  - 타임라인에 놓으면 서버로 올려 `projects/<id>/media/` 에 받은 뒤, 놓은 자리부터 차례로 클립이 됩니다.
  - 소스 칸에 놓으면 가져온 파일에만 넣습니다.
  - 이름 · 크기가 같은 파일은 다시 받지 않습니다.
- **폴더 추가**: 서버가 폴더 고르는 창을 띄웁니다. 폴더 빼기는 목록에서만 빼고 파일은 그대로 둡니다.

**이펙트**: 클립 위에 끌어 놓거나, 클립을 고른 뒤 타일을 누릅니다.
- 골라 둔 클립 위에 놓으면 고른 것 전부에, 그룹은 늘 같이 걸립니다.
- 화면 효과는 원본 클립 (V1) 에만 걸립니다.

| 갈래 | 들어 있는 것 |
|---|---|
| 화면 효과 | 확대 · 크게 확대 · 다가가기 · 빠르게 다가가기 · 물러나기 · 흔들기 · 세게 흔들기 · 흐리게 · 흑백 · 번쩍 (클립 시작) · 비네트 · 좌우 반전 |
| 색 | 흑백 · 강한 흑백 · 따뜻하게 · 차갑게 · 선명하게 · 바랜 색 · 청록 주황 · 세피아 · 시네마 · 노을 · 밤 · 파스텔 · 빈티지 · 밝게 · 어둡게 (색을 통째로 바꿈) |
| 전환 | 디졸브 · 검은 화면 · 흰 화면 · 닦기 ← → ↑ ↓ · 밀기 ← → ↑ ↓ · 원형 (0.5초) |

- 화면 효과의 세기 · 길이는 인스펙터 **효과**에서 바꾸고 뺍니다.
- 소리 효과는 없습니다. 소리에는 말씀하시기 전에 필터를 걸지 않습니다.

### 전사 자막 탭

| 동작 | 결과 |
|---|---|
| 낱말 누르기 | 클립 목록에서 바로 빼고 / 되살림 |
| Shift | 여럿 |
| 두 번 누르기 | 그 자리로 이동 |

- 뺄 때는 앞뒤 쉼의 가운데까지 자릅니다.
- 되살릴 때는 앞 0.10 · 뒤 0.15초 여유를 붙입니다.

### 렌더 탭

| 묶음 | 설정 |
|---|---|
| 파일 | 작업 폴더 · 내보낼 곳 · 기준 언어 |
| 영상 | 코덱 (H.264 / H.265), 인코더 (자동 / 소프트웨어), 화질, 해상도, 프레임 |
| 소리 | 비트레이트, 목표 크기 (LUFS) |

- **인코더**: 자동은 그래픽 카드를 먼저 써서 빠르고, 소프트웨어는 느리지만 화질이 가장 좋습니다.
- **화질**: 12–32, 기본 20. 숫자가 작을수록 화질이 좋고 파일이 큽니다.
- **해상도**: 영상 방향의 크기만 나옵니다 (세로 영상이면 세로 크기만). 원본보다 크게 하면 늘리기만 됩니다.
- **목표 크기**: 고정 이득 한 번으로 맞춥니다. 리미터가 없어서 최고점 (-1.5 dB) 에 걸리면 덜 올라갑니다.
- 모든 설정이 기본이면 구운 조각을 그대로 이어 붙입니다. 하나라도 바꾸면 마지막에 한 번 더 인코딩합니다 (몇 초 더, 화질 한 세대 더).
- 파일 형식은 mp4 만 됩니다.
- **렌더** 단추는 맨 아래에 있습니다.
  - 진행 칸에 단계 · 막대 · 경과 / 남은 시간 · 마지막 기록이 나옵니다.
  - 끝나면 프로젝트를 다시 읽습니다.

## 3. 알아 둘 것

- **미리보기와 렌더**: 화면 효과 · 색 · 전환은 같은 계산을 씁니다. 다만 미리보기는 컷 이음에서 그림이 조금 끊길 수 있고, + dB 소리는 1 배로 들립니다.
- **자막 순서**: 비디오 트랙에 놓아도 완성본에서는 자막이 덧 영상 · 그림 위에 그려집니다. 트랙은 놓는 자리입니다.
- **트랙 옮기기**: 원본 파일 경로가 필요합니다. 옛 프로젝트는 렌더를 한 번 하거나 AI 편집이 한 번 돌면 됩니다.
- **AI 가 컷을 바꾸면** 덧 클립 · 새 자막은 원본 리플에 밀리지 않아 (놓은 시각 그대로) 자리가 어긋날 수 있습니다.
