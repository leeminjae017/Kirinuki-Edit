재는 스크립트: `analyze_refs.py` · `analyze_layout.py` · `analyze_push.py`. 결과: `refs_metrics.json` · `refs_layout.json` · `refs_push.json`.

- **"화면 바뀜"** = 제목 띠를 뺀 창 안에서 색 분포나 밝기가 크게 달라진 순간 (0.3초 안의 것은 하나). 문턱은 눈대중이라 절대값보다 채널끼리의 차이로 읽는다.
- **느린 확대(켄 번스)는 드물다.** 0.8초 넘게 붙잡은 샷 가운데 크기가 3% 넘게 변한 샷이 0 ~ 25% (대부분 0 ~ 10%). 역동성은 카메라 움직임이 아니라 **창 안의 소스가 자주 바뀌는 데서** 나온다.
- 확대 · 흔들림(프레임 사이 변환)은 20편 전부 거의 0 - 화면을 흔드는 효과는 안 쓴다.
- **소리 (확인 안 함):** 센 소리 순간이 초당 0.45 ~ 1.35 로 삼성(1.28)과 비슷하고, 소리 바닥도 -33 ~ -57 dB 로 삼성(-36)과 섞여 있다. 이 방법으로는 효과음 · 배경음이 말소리와 안 갈린다 - 들어서 확인해야 한다.

## 네 채널이 같이 쓰는 문법 (본 것)

그림: `img/reps.jpg` (채널마다 한 장), `img/sheet_*.jpg` (5편 x 8장), `img/strip_*.jpg` (바뀜 전후 1.5초, 10fps).

1. **레터박스 틀.** 위 · 아래가 검정 띠이고 가운데가 영상 창이다. 잰 창 위치: 위 띠 화면 높이의 15 ~ 22%, 아래 띠 5 ~ 23%.
2. **위 띠 = 영상 내내 떠 있는 훅 제목.** 한두 줄, 굵은 고딕, 흰 글에 **핵심 낱말만 색** (노랑이 가장 흔함, 정타비는 주황 · 빨강 · 파랑 · 분홍). 예: "치지직 **감쓰통** VS 치지직 **변기통**".
3. **아래 띠 = 채널 표식.** 미도미도 마요는 로고, 정타비는 "아라하시 타비 / 25/11/19 [타비 마술쇼]" (방송 이름 · 날짜), 형독 · 라코코는 비워 둔다.
4. **자막은 창 안 아래쪽**, 말에 맞춰 바뀐다 (지금 담유이와 같다). 채널마다 글꼴이 뚜렷하다:
   - 라코코: 크고 두꺼운 붓 느낌 글꼴, 굵은 검정 외곽선, 두 줄, 강조는 빨강
   - 정타비: 둥근 손글씨 글꼴, 흰 글 + 어두운 외곽선, 둘이 나오면 "(흑돌)" "(백돌)" 이름표
   - 형독: 흰 상자에 검정 글 (라벨), 강조 낱말은 노랑 · 파랑
5. **창 안의 소스가 1초 안팎마다 바뀐다.** 바뀌는 종류 (많이 본 순):
   - 다른 장면으로 **바로 컷** (방송 화면 · 게임 · 3D 모델 다른 각도)
   - **얼굴 가까이 자르기** (반응 순간에 얼굴만 크게)
   - **끼워 넣는 화면**: 채팅 · 후원 · 커뮤니티 글 캡처, 캠 화면(PiP), 실제 사진
   - **스티커 · 밈 누끼** (페페 개구리, 손가락 사진), **효과 입자** (라코코의 초록 반짝이)
   - **그래픽**: 움직이며 따라가는 **초점 괄호 [ ]** (정타비 오목), 화살표와 이름 붙은 **과정 도표** (정타비), **말풍선** (형독 · 미도미도), **장 제목** "0. 사건의 시작 / 1. 부정 / 2. 분노" (라코코)
   - **글자 카드**: 흰 바탕에 검정 글로 상황 설명 후 영상으로 컷 (형독)
6. **들어오는 방식.** 대부분 바로 컷이다. 끼워 넣는 그림은 작은 창에서 창 가득으로 **커지며 들어오고** (정타비 과정 도표, 약 0.8초), 초점 괄호는 **미끄러져 옮겨 간다**. 화면 흔들기 · 화려한 전환 효과는 못 봤다.

## 채널마다 다른 점

- **형독** - 실사 사진 · 영상, 얼굴 합성(머리를 다른 몸에), 만화 말풍선, 배경 사진 위에 사람 누끼. 사용자 설명대로 소스를 새로 만드는 쪽이다.
- **미도미도 마요** - 캐릭터를 직접 그린 일러스트(마스코트 · 단면도 · 여러 표정)가 대부분. 따라 하려면 그림을 새로 그려야 한다.
- **라코코** - 3D 모델 영상을 각도 · 거리 바꿔 가며 빠르게 이어 붙이고, 방송 캡처 · 캠 · 채팅을 겹친다. 장 제목으로 이야기 구간을 나눈다. **네 채널 중 바뀜이 가장 잦다.**
- **정타비** - 방송 화면을 그대로 쓰되 자르기 · 초점 괄호 · 도표 · 밈 스티커로 "지금 볼 곳"을 짚어 준다. 아래 띠에 방송 출처를 적는다.

## 담유이 삼성과 견주면

지금 삼성은 프리셋 배경 위에 담유이 캠 한 장면이 38초 내내 같은 크기로 있고, 자막만 바뀐다 (화면 움직임 0.4). 참고 채널은 **자막 말고도 1초 안팎마다 창 안의 무언가가 바뀐다.**

지금 소스로 **할 수 있어 보이는 것** (짐작 - 적용은 안 했다):

| 기법 | 참고 | 삼성에서의 예 | 필요한 소스 |
|---|---|---|---|
| 레터박스 + 훅 제목(색 낱말) | 넷 다 | "아이폰 14년 쓴 유이가 **삼성**으로 간 이유" | 없음 |
| 얼굴 가까이 자르기 (강조 · 발끈 줄에서) | 라코코 · 정타비 | "330만원 실화냐~" 에서 얼굴 확대 | 없음 (지금 캠) |
| 주제 그림 끼워 넣기 (커지며 들어옴) | 라코코 · 정타비 | 폴드 8 · 아이폰 사진, 가격표, 환율 그래프 | 인터넷 이미지 |
| 채팅 캡처 / 말풍선 | 형독 · 정타비 | "삼성 안 쓴다고?" 는 채팅을 받아 읽는 말 | 원본 채팅 칸 잘라 오기 (소스 안에 있다) |
| 초점 괄호 · 화살표 | 정타비 | 가격 숫자 · 폰 부분 짚기 | 직접 만들면 됨 (재사용) |
| 밈 스티커 · 효과 | 라코코 · 정타비 | "승자죠?" 에 왕관 · 반짝이 | 인터넷 이미지 + 누끼 |
| 장 제목 | 라코코 | "1. 가격 / 2. 환율 / 3. 결론" | 없음 |
| 아래 띠 출처 표시 | 정타비 | "담유이 / 날짜 [방송 이름]" | 없음 |

- **박자 목표 (짐작):** 38초 영상이면 라코코 박자로 30 ~ 55번, 정타비 박자로 12 ~ 30번 바뀐다. 두 채널 가운데쯤 **25 ~ 40번**이 첫 시도로 무난해 보인다.
- **형독 · 미도미도 마요 방식(소스를 새로 그리거나 합성)**은 사용자 말대로 따라가기 어렵다. 가까운 것으로는 얼굴 누끼를 다른 배경에 얹기 정도가 있다.
- **재사용할 소스 창고:** 초점 괄호 · 화살표 · 말풍선 · 장 제목 카드 · 강조 스티커는 직접 만들어 한 곳에 두면 다른 프로젝트에서 그대로 쓴다. 인터넷 이미지(제품 사진 · 로고 · 밈)는 **저작권 · 상표권**을 따져야 한다 - 받을 때 출처와 이용 조건을 같이 적어 두는 편이 안전하다.

## 한계 (확인 안 한 것)

- 360p 로 받아 자막 글꼴 이름 · 정확한 색 값은 못 쟀다 (눈으로 본 인상이다).
- 영상마다 8장 + 바뀜 전후 스트립 6개만 봤다. 20편 전체를 처음부터 끝까지 본 것은 아니다.
- 바뀜 · 느린 확대의 문턱은 눈대중이다.
- 효과음 · 배경음은 숫자로 못 갈랐다 - 들어서 확인해야 한다.
