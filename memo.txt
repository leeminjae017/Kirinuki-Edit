편집 관리 대시보드 ui

탭은 총 3개 AI 편집 사용자 편집 (가능하면 아이콘 형식으로 쓸 것)

모든 파일 / 폴더는 드래그&드랍을 적용한다

AI 편집                    
스타일 분석 레이아웃(탭) | 스타일 적용 레이아웃(탭)  | 추가 프롬프트 레이아웃(공통)                   | 로그(이모티콘 금지, 공통)
원본 파일(폴더)              | 편집 대상 파일(폴더)        | ==                                                       | info 콤보박스(단계: INFO, WARNING, ERROR)
편집본 파일(폴더)           | 스타일 선택(콤보박스)      | 다국어 설정(입력 필드)                            |
				   |					 | 자막만 다국어 설정 가능                          | 
스타일 분석(버튼)           | 스타일 적용(버튼)            | 언어를 3개를 적었다면 결과 영상도 3개      |

사용자 편집
전반적인 사용자 편집 ui는 일반적인 편집 프로그램의 구성을 따른다

선택 레이아웃            | 미리보기 레이아웃      | 인스펙터 레이아웃
폴더, 자막, 오디오등등 | 영상 미리보기(확인용) | 요소 수정 (자막의 경우 화자, 자막 내용, 자막 디자인을 포함)

기본 상태에서
영상(클립, 레이어1)
오디오(클립, 레이어1)

추가로 자막, 효과음, 영상 클립 추가 가능 -> 레이어 형태
영상 클립(블록 형식), 자막 클립, 오디오 클립등, 직접 컷을 할 수 있게 지원하고 기본적으로는 영상 / 오디오 타임스탭프 동기화 but 개별로도 위치 이동 가능하게 할 것

렌더링 시에만 전체에 실제로 적용, ai는 필요한 경우에만 사용 (토큰 관리)
자막의 경우 csv에서 열기, csv 수정 내용 반영을 지원

말그대로 관리 대시보드임 -> llm은 클로드를 그대로 쓰되 내가 알아보기 쉽게 하기 위해서 만드는 것임 (클로드 api 추가 결제 사용x)
