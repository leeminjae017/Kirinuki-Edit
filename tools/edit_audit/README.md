## 굽기 전 - 어디를 어떻게 자를지 정할 때

| 도구 | 하는 일 |
|---|---|
| `speech_map.py` | 전대역(-52/-60, 0.30초) 말 지도. **컷은 여기 나온 덩이 사이에서만** |
| `syllables.py` | 소리 봉우리·골 (다른 도구들이 쓴다). 봉우리 세기로 음절을 맞추려 하지 말 것 - 8글자에서 3-5개밖에 안 잡힌다 |

| `fit.py` | **자막 한 줄이 글자 크기를 줄이지 않고 들어가나 · 둘로 나눈 줄이 치우쳤나** (프리셋 글꼴로 잰다, 편 폴더를 인자로). 쓰기 전 `fit.py <편> "글"` |
| `cutmatch.py` | 쉼 안에서 **화면이 가장 덜 튀는** 컷 자리를 고른다. 차이는 8x8 칸 최대차이 (평균은 팔 움직임을 놓친다) |

## 낱말 자리를 다툴 때 (제일 비쌌던 실수)

무성 마찰음(ㅅ·ㅆ·슈·ㅎ)은 **대역 레벨에서 안 보인다** - "슈" 가 -64dB 라 쉼으로 읽혔다.
3-7kHz 와 200-1500Hz 의 비를 재면 +10dB 넘게 뜬다:

```python
S = np.abs(np.fft.rfft(a * np.hanning(n))) ** 2
hi = S[(f >= 3000) & (f < 7000)].sum(); lo = S[(f >= 200) & (f < 1500)].sum()
10 * np.log10(hi / lo)      # 마찰음이면 0dB 위, 모음이면 -20dB 아래
```

**위스퍼 낱말 시각은 쉼 앞뒤에서 믿지 않는다.** 이 편에서 "슈트를 4.32-6.38" 로 두 덩이에 걸쳐 잡아
놓아 1.6초를 헤맸다. 진짜 자리는 마찰음으로 찾았다 (5.92).

## 편마다 먼저 다시 재는 것 (퍼리 취향 2026-09-28)

이 도구들의 문턱은 **소스마다 다르다.** 옮겨 심고 바로 돌리면 헛경보가 난다. 먼저 이 셋을 재고 고친다:

    ffmpeg -nostats -i src_audio.wav -af ebur128 -f null -      # 통째 크기
    말/쉼 20ms RMS 분포 (p5 · p50 · p90)                        # 문턱을 여기서 정한다
    대역 트랙(src_level.wav)이 말에서 몇 dB 높은지               # speech_map 의 `L - N`

| 편 | 통째 | 말 p90 | 쉼 p50 | speech_map 문턱 | 대역 차 |
|---|---|---|---|---|---|
| 프젝아 모캡 | -28 LUFS | -19 | -64 | -52 / -60 | +6 |
| 퍼리 취향 | **-37.4 LUFS** | -34.6 | -56 | **-47 / -53** | +3.8 |

- `verify_runs.py` 의 `GAIN` 은 빌드 로그의 고정 이득으로 바꾼다. 조각별 `gainDb` 는 스크립트가 알아서 뺀다
- `check.py` 는 말 문턱을 (p5+p95)/2 로 스스로 잡는다 - 고칠 것 없다
- **조각마다 말 크기를 재서 고르게 한다** (`edit.json` 의 `gainDb`). 퍼리 취향은 조각 3 이 다른 데보다 4.5dB
  낮아 "나 믿는다" 가 묻혔다. loudnorm 이 아니라 조각에 이득 한 번 (소리에는 필터를 걸지 않는다)
- **`edit.json` 을 고쳤으면 `cuts` 를 따로 돌린다.** `build` 는 있는 `cuts.json` 을 그냥 쓴다 -
  `gainDb` 를 넣고 build 만 했더니 조용한 채로 다시 구워졌다 (퍼리 취향 1차)

## 자막이 없는 자리 (퍼리 취향 재편집 3, 2026-09-28)

사용자가 자막 줄을 지우라고 하면 **그 자리는 비워 둔다.** 앞뒤 줄을 늘려 먹이면 자막이 딴 말 위에 뜬다.
줄 끝은 **제 조각 끝 + 0.10초** 까지만 (컷에서 깜빡이지 않을 만큼). `scenes.py` 는 자막 없는 자리를
지나가는 컷과 0.10초짜리 넘김을 흠으로 세지 않는다.
